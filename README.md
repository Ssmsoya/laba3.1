# LAST DAY

3D-симулятор выживания в постапокалиптическом кафе. Работай с покупателями, производи пайки и воду, защищайся от зомби, нанимай сотрудников и переживай смены.

## Возможности

3D-кафе, посетители, зомби, охранник, кассир, невидимый разведчик, производство, улучшения, ежедневные зарплаты, отчёты, сохранения и настройки звука.

## Управление

WASD — ходьба; Shift — бег; Space — прыжок; Ctrl — присесть; E — взаимодействие; ЛКМ / F — удар ломом; G — бросить тело; L — свет; O — ставни; 1 — паёк; 2 — вода; 3 — перевязка; Esc — пауза.

## Структура

- `index.html` — главная страница игры.
- `css/style.css` — оформление меню и HUD.
- `js/game.js` — исходная игровая логика и аудиоменеджер, без переписывания ИИ и экономики.
- `assets/audio/music/` — две оригинальные инструментальные композиции OGG.
- `assets/audio/zombies/`, `assets/audio/humans/` — оригинальные **синтезированные**, а не записанные актёрами, голосоподобные эффекты OGG.
- `assets/textures/` — дополнительные текстурные изображения. Основные игровые материалы генерируются программно.
- `.nojekyll` — отключение Jekyll при публикации.

## Локальный запуск

Распакуйте проект. Из папки с `index.html` выполните `python -m http.server 8000` (на Windows можно `py -m http.server 8000`), затем откройте `http://localhost:8000/`. Это нужно для корректной загрузки файлов браузером; устанавливать сервер на GitHub не требуется.

## GitHub Pages

1. Создайте репозиторий.
2. Загрузите **содержимое** папки `LAST-DAY`, а не папку целиком и не ZIP. Файл `index.html` должен оказаться в корне репозитория.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните настройки и дождитесь публикации во вкладке Actions.
7. Откройте `https://USERNAME.github.io/REPOSITORY/`.

GitHub Pages размещает статические HTML/CSS/JS-файлы и не запускает серверный код.

## Аудио и лицензии

Музыка и голосоподобные эффекты созданы для этого проекта средствами синтеза и кодированы как настоящие OGG Vorbis. Это **не полевые записи и не актёрские голоса**. Остальные звуки (оборудование, шаги, двери, ветер, удары и интерфейс) пока создаются Web Audio API во время игры. Аудиофайлы не заимствованы у сторонних авторов; сторонних звукозаписей нет. Управление громкостью музыки, окружения и эффектов находится в настройках. Браузер разрешает воспроизведение только после пользовательского действия.

**Ограничение:** библиотека Three.js 0.150.1 загружается через jsDelivr CDN. Без интернета или при блокировке CDN 3D-игра не запустится. Полностью автономной эта сборка не является.

## Сохранения

Прогресс и настройки сохраняются в `localStorage` браузера для адреса сайта. Очистка данных сайта или смена адреса может удалить сохранения.

## Возможные проблемы

- **Белый экран / текст вместо игры:** проверьте, что `index.html` — настоящий HTML-файл и лежит в корне репозитория; не загружайте содержимое JavaScript вместо HTML.
- **Чёрный экран:** проверьте WebGL, интернет, доступность Three.js CDN и консоль браузера (F12).
- **404:** проверьте структуру папок, регистр букв, настройку Pages и вкладку Actions.
- **Нет музыки:** нажмите кнопку игры или настроек, проверьте громкость и mute, убедитесь, что файлы OGG доступны; проверьте консоль браузера.
